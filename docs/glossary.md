# Glossary

**Arrangement** – the order of a song's parts. See [[lyrics|Lyrics]].

**Audience screen** – the screen the congregation sees. See [[ProPresenter]].

**Connected accounts** – our YouTube channel and Facebook page, signed in inside Streamlabs so it can stream to both. See [[connected-accounts|Connected accounts]].

**Go Live** – the button in [[Streamlabs]] that starts the stream. See [[going-live|Going live]].

**Library** – where all songs and presentations are saved in [[ProPresenter]].

**Live stream** – sending the service to the internet in real time, on [[YouTube]] and [[Facebook]].

**Lower third** – text shown on the bottom part of the screen, like a name or scripture reference.

**Playlist** – the list of everything for one service, in order. See [[ProPresenter]].

**Scene** – one "look" in [[Streamlabs]] (camera, slides, logo).

**Stage screen** – the screen the band and pastor see. See [[ProPresenter]].
