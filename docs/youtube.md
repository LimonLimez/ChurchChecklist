# YouTube

We stream every Sunday service to the church YouTube channel using [[Streamlabs]].

> ✏️ **To fill in:** the link to our channel, and who has access to manage it.

## Title format

Use the same format every week so people can find our services:

```
Sunday Service | [Sermon Title] | [Pastor Name] | [Month Day, Year]
```

## Description template

```
Welcome to Glad Tidings Church in Anderson, Indiana!

Today's message: [Sermon Title]
Speaker: [Pastor Name]
Scripture: [References]

[Add church website, giving link, and social links here]
```

## Checking that we're live

Open the channel on a phone and look for the red **LIVE** label. Check that you can **see and hear** the stream.

## YouTube Studio

**YouTube Studio** (studio.youtube.com) is where you manage the channel: titles, thumbnails, and past streams. You can change a title there after the stream if you made a mistake.
