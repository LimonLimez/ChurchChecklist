# Welcome to the Media Team Wiki

Welcome to the **Glad Tidings Church media team**! This wiki teaches you everything you need to run the screens and the live stream. Any <a class="wikilink">blue word</a> is a link: click it to learn more about it, just like Wikipedia.

## Our weekly rhythm

| When | What happens | Checklist |
|------|--------------|-----------|
| **Thursday** | Prep: upload lyrics and slides, verify keys, set up the stream | [[checklist:thursday]] |
| **Sunday** | Run worship lyrics, **go live after worship ends**, run the sermon | [[checklist:sunday]] |

## The software we use

- [[ProPresenter]]: puts lyrics, scripture, and slides on the screens.
- [[Streamlabs]]: sends our service live to [[YouTube]] and [[Facebook]] at the same time.
