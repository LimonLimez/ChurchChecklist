# Lyrics

Getting lyrics into [[ProPresenter]] is part of [[checklist:thursday|Thursday Prep]].

## Steps

1. **Get the song list** from the worship leader: songs, order, and arrangement.
2. **Search the ProPresenter Library** for each song. If it's there, use it.
3. **If it's new,** create a new presentation and add the lyrics.
4. **Check every slide:** no typos, 2 to 4 lines per slide, easy to read.
5. **Set the arrangement** (verse/chorus order) to match how the band will play it.
6. **Add it to Sunday's playlist** in the right order.

## Verifying keys

Confirm the key and arrangement of each song with the worship leader, so everything on the screens matches what the band plays.
