# Troubleshooting

> **First:** stay calm. Put up a safe slide (the church logo) and ask for help.

| Problem | Try this |
|---------|----------|
| Nothing on the screens | Check the screens are on and on the right input. In [[ProPresenter]], check the screen settings. |
| Wrong slide showing | Use the **Clear** buttons in ProPresenter. |
| Stream won't start | Check the internet. Check the [[stream-keys|stream keys]]. Restart [[Streamlabs]]. |
| Stream has no sound | Check the Audio Mixer in Streamlabs, and check the cable from the sound board. |
| Stream is choppy | Check the internet connection. Look for "dropped frames" at the bottom of Streamlabs. |
| Open button doesn't work | The wiki server must be running on the MacBook. See [[macbook|The media MacBook]]. |
